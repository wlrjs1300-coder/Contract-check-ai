# v0.8.0 durable analysis jobs API

Analysis creation endpoints validate ownership and source revision, enqueue work,
and return without waiting for provider execution.

```json
{"job_id": "uuid", "document_id": "uuid", "status": "pending"}
```

Clients poll `GET /analysis-jobs/{job_id}`. States are `pending`, `running`,
`completed`, and `failed`. The same active request returns its existing job.
Completed and failed jobs do not block a new request.

Worker IDs, leases, heartbeats, fingerprints, dedupe keys, and raw exceptions
are internal and are not returned.
