# v0.8.0 Release Closure

## 완료 범위

- Durable jobs: enqueue-only API, DB worker, atomic claim, lease/heartbeat, stale recovery, bounded retry와 active dedupe
- Operations: 공용 image 정의, API/worker/DB/migrate Compose 분리, health/readiness, production fail-closed, structured logging, graceful shutdown
- Boundary protection: 선택적 쓰기 API rate limit, text/PDF 크기·형식·filename 검증, PDF temp cleanup, extraction 문자·페이지 제한, 안전 오류와 관련 테스트

## 명시적 제외

Redis/distributed limiter, Kubernetes, Terraform, CI/CD 자동 배포, 외부 observability, WAF, antivirus, malware sandbox, archive extraction, 신규 OCR/PDF/docx parser, WebSocket/SSE, cancellation, billing, 관리자 UI와 신규 AI provider는 후속 범위다.

여러 API replica에서 rate limit bucket은 공유되지 않는다. 실제 Docker image/container smoke test와 실제 MySQL 연동은 실행 기록이 없으면 완료 항목으로 간주하지 않는다.
