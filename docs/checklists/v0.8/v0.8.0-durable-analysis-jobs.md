# v0.8.0 durable analysis jobs checklist

- [x] Analysis APIs enqueue `pending` jobs
- [x] Active duplicate requests reuse the existing job
- [x] Worker claims with a conditional database update
- [x] Worker heartbeat extends an owned lease
- [x] Expired leases recover to `pending` or `failed`
- [x] Retryable provider errors use bounded backoff
- [x] Non-retryable failures terminate without raw error storage
- [x] Result writes and completion share a transaction
- [ ] Production readiness endpoint
- [ ] Docker web/worker process separation
- [ ] Migration one-shot deployment
- [ ] Structured JSON logging and metrics
- [ ] Rate limiting and upload hardening
